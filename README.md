# Music Note Staff Position Flashcard Quiz

An SVG-drawn musical staff displays a note on a treble or bass clef. Click one of the seven note buttons (C through B) to identify the pitch. After answering, the correct note button lights up green and any wrong guess turns red, along with the full note name and octave in the feedback line.

## Features

- SVG staff drawn in-browser with proper treble (𝄞) and bass (𝄢) clef symbols
- Ledger lines rendered automatically for notes above/below the five staff lines
- Three difficulty modes: Treble only, Bass only, or Both clefs mixed
- Tracks correct, wrong, current streak, and overall accuracy percentage
- Note stem direction flips correctly based on note position (above/below middle)
